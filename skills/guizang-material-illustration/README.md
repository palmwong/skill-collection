## 功能简介

一个面向 Agent 环境的配图 Skill，把文章、笔记、图表截图、产品概念、工作汇报、教学材料等转化为**带中文标签的歸藏材质插画**。专门解决"中间那张图"的问题——不是装饰图，而是能讲清楚概念的说明性配图。

## 核心能力

- **解释图**：把抽象概念、流程、机制、系统关系画成带标签的图
- **图表美化**：从截图或原始数据中抽取语义，重绘成材质化图表（保留数据、坐标、单位、结论）
- **参考辅助出图**：遇到冷门概念、品牌、模型、科学装置、历史物件时，先查参考信息和参考图，再统一转成歸藏材质风格

## 支持的图片类型

概念拆解图、流程图、循环机制图、对比图、层级/架构图、场景解释图、科学机制图、人文意象图、材质化图表（柱状图/折线图/甘特图/桑基图/热力图/漏斗图/累计流图）、参考辅助图等。

## 使用场景

- 长文章配图：拆出 1-4 个核心概念，各生成一张解释图
- 产品/技术说明：先查参考，再做流程图、层级图、系统关系图
- 图表截图美化：抽取数据语义后重新生成材质化图表
- 工作汇报：进展、风险、决策、下一步四象限或流程配图
- 教育解释：科学/物理/生物/历史概念的可视化
- 社交卡片联动：先生成中心图，再交给 `guizang-social-card-skill` 排版成 3:4 小红书卡片

## 明确边界

**适合做**：文章配图、知识解释图、产品机制图、工作汇报配图、数据图表美化、教学材料配图、人文观点配图、社交卡片中心图、PPT 中心插画、冷门概念视觉解释

**不适合做**：完整小红书卡片排版（用 Social Card Skill）、完整 PPT 结构设计（用 PPT Skill）、真实摄影修图、人像写真、长文海报排版、需要严格出版级数据制图的科研图

## 核心设计原则

1. 图要讲人话：标签短、具体、能指向对象
2. 图内可以有字：解释图不是纯装饰，必要标签应直接生成在图里
3. 数据不能编：图表类先保证数值、坐标和单位正确
4. 参考只补事实：为了画对，不是为了抄风格
5. 不让用户选内部模式：Agent 自动判断类型
6. 中心图与外层排版分工：本 skill 负责配图，Social Card / PPT Skill 负责整页排版
7. 小图也要读得清：进社交卡片时标签和主体缩放后仍可辨识
