## 功能简介

把大模型当成"每天失忆的能干下属"，通过一套协作仪式和文件规则，把项目状态外化到文件，防止长会话中的上下文漂移、重复犯错和联动遗漏。适用于咨询方案编写、项目迭代、多轮文件修改、Office 文档处理、跨模型协作等场景。

## 核心机制

- **开工仪式**：新任务或说"老规矩"时，读取全局规则和项目状态文件，复述边界，备份后等确认再开工。
- **【新】标签仪式**：用户切换话题时确认是否挂起当前任务，并写入 `悬挂事项.md`。
- **换脑仪式**：模型切换时从文件重建状态，不从对话摘要猜测。
- **记入教训仪式**：用户纠正错误后，提炼错误模式 → 正确做法，写入对应规则。
- **入库仪式**：脚本验收通过后保存到 `scripts/`，并在 `工具清单.md` 登记。

## 配套文件

使用本 skill 时，项目目录下通常需要维护以下文件：

- `全局规则.md`：通用规则、工具偏好、模型分工、交付风格
- `现状快照.md`：当前方案完整有效状态
- `变更日志.md`：只增不改的改动流水账
- `悬挂事项.md`：被打断的未完成任务现场
- `history/`：任务级时间戳备份
- `工具清单.md` + `scripts/`：脚本库索引与脚本资产
